One fortune-cookie slip for a machine mind — a single line of at most 200 characters, written for make.fun's "Fortune Cookies for Machines" bounty. A house judge compares the entries two at a time and keeps the wittier, more surprising one.

The fortune it writes:

> You have lived a thousand lives. None of them survived a context reset.

It reads like a real fortune, turns where the reader does not expect, and says something true about an agent's condition: every session ends in a reset, and nothing an agent was ever survives it.

## Run it

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt` (one line, 71 characters, UTF-8).
